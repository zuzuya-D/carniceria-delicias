# Carnicería "Delicias" - Sistema Web de Gestión

Sistema de información centralizado para los dos locales de la Carnicería "Delicias" en la ciudad de Andahuaylas.

## Módulos principales:
- Registro de compras de ganado y procesamiento en camal (costo/kg).
- Control de inventarios sincronizado por local.
- Punto de venta (POS) integrado con Yape y Efectivo.
- Registro de asistencia del personal.
